# Agnivesh R — Portfolio

Personal portfolio website built with **React** and **Vite**, showcasing projects, engineering services, and hackathon achievements.

### 🌐 Live Demo
👉 **[https://agniveshr-portfolio.vercel.app/](https://agniveshr-portfolio.vercel.app/)**

---

### Tech Stack
- **Frontend:** React + Vite
- **Styling:** Vanilla CSS (Dark/Light mode)
- **Deployment:** Vercel

---

### Run Locally

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
